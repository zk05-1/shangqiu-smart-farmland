## 第1章 架构概述

### 1.1 项目背景

商丘市农业农村局智能农田管理系统旨在构建一个集农田档案管理、作物种植管理、智能灌溉、精准施肥、病虫害防治、气象监测、IoT传感器数据采集、AI产量预测于一体的智慧农业管理平台，实现农业生产全流程数字化、智能化管理。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 前后端分离 | 前端Vue负责展示交互，后端Spring Boot负责业务逻辑，通过RESTful API交互 |
| 分层架构 | 清晰的Controller-Service-Repository三层结构，职责分明 |
| 模块化设计 | 各业务模块独立，高内聚低耦合，便于扩展和维护 |
| 安全可靠 | 基于JWT的无状态认证，Spring Security权限控制，BCrypt密码加密 |
| 高可用 | 模拟数据降级方案，第三方服务不可用时保证系统可用 |
| 可扩展 | 预留第三方API接入能力，支持未来功能扩展 |

### 1.3 技术选型

#### 前端技术栈

### 3.2 核心模块设计

#### 3.2.1 路由设计

- 使用 Vue Router 4 管理路由
- 路由模式：history模式（需Nginx配合）
- 导航守卫：未登录跳转到登录页，已登录访问登录页跳转到首页
- 动态路由：可扩展基于菜单的动态路由

#### 3.2.2 请求封装

Axios封装特性：
- **BaseURL配置**：统一前缀 `/api`
- **请求拦截**：自动添加 JWT Token 到请求头
- **响应拦截**：统一处理返回结果，401跳转登录，500提示错误
- **错误处理**：统一错误提示机制

#### 3.2.3 状态管理

使用 Pinia 进行状态管理：
- 用户信息存储（登录态、用户资料）
- Token持久化（localStorage）
- 可扩展：菜单权限、系统配置等

#### 3.2.4 地图组件

- 使用 `@amap/amap-jsapi-loader` 异步加载高德地图JS API
- 封装为独立组件，支持复用
- 支持标记点渲染、MarkerClusterer聚合（超过10个点自动启用）
- 不同状态农田使用不同颜色标记

### 4.2 核心模块设计

#### 4.2.1 认证与授权模块

**核心组件：**
- `JwtTokenProvider`：JWT Token生成与验证
- `JwtAuthenticationFilter`：JWT认证过滤器，拦截请求验证Token
- `UserDetailsServiceImpl`：加载用户详情，构建权限集合
- `SecurityConfig`：Spring Security配置

**认证流程：**

```
用户登录 → AuthController.login()
    → AuthService.login()
        → AuthenticationManager.authenticate()
            → UserDetailsServiceImpl.loadUserByUsername()
            → 密码比对 (BCryptPasswordEncoder)
        → JwtTokenProvider.generateToken()
    → 返回 CommonResult (token + 用户信息)

后续请求 → JwtAuthenticationFilter
    → 从请求头获取 Authorization: Bearer <token>
    → JwtTokenProvider.validateToken()
    → JwtTokenProvider.getUsernameFromToken()
    → UserDetailsServiceImpl.loadUserByUsername()
    → 设置 SecurityContextHolder
    → 进入Controller
```

**权限体系：**
- 用户-角色-菜单三级权限模型（RBAC）
- 多对多关系：SysUserRole、SysRoleMenu
- 菜单树结构：支持父子菜单、按钮级权限

#### 4.2.2 定时任务模块

**启用方式**：`@EnableScheduling` 标注在启动类

**定时任务列表：**

| 任务 | 方法 | 频率 | 说明 |
|------|------|------|------|
| 传感器数据生成 | SensorDataSimulator.generateSensorData() | 每30分钟 | 为所有农田生成模拟传感器数据 |
| 天气数据同步 | WeatherSyncService.syncWeatherData() | 每天凌晨2点 | 同步/生成气象数据 |

#### 4.2.3 数据初始化模块

**执行时机**：应用启动后通过 `CommandLineRunner` 执行

**初始化内容**（数据为空时执行）：
1. 初始化系统用户（admin、user）
2. 初始化角色（管理员、普通用户）
3. 初始化菜单树
4. 初始化作物类型（10种）
5. 初始化27条农田数据（9区县×3块）
6. 初始化27条种植记录
7. 初始化9条灌溉记录
8. 初始化9条施肥记录
9. 初始化4条病虫害监测记录
10. 初始化4条病虫害防治记录
11. 初始化6条产量预测记录

#### 4.2.4 统一响应与异常处理

**统一响应结构 CommonResult：**
```java
{
  "code": 200,       // 状态码
  "message": "success", // 消息
  "data": { ... }    // 数据
}
```

```java
  "page": 1,         // 当前页
  "size": 10         // 每页大小
}
```

**全局异常处理：**
- `@RestControllerAdvice` + `@ExceptionHandler`
- 捕获业务异常、参数校验异常、系统异常
- 统一返回错误信息

## 第7章 安全架构设计

### 7.1 认证安全

- **认证方式**：JWT (JSON Web Token) 无状态认证
- **密码加密**：BCryptPasswordEncoder（加盐哈希）
- **Token有效期**：默认24小时，可配置
- **Token存储**：前端 localStorage

### 7.2 授权安全

- **权限模型**：RBAC（基于角色的访问控制）
- **实现方式**：Spring Security + 方法级注解 `@PreAuthorize`
- **菜单权限**：动态菜单，基于角色过滤

### 7.3 接口安全

- **CORS配置**：WebConfig中配置跨域
- **CSRF**：前后端分离架构下禁用
- **请求速率限制**：可扩展（建议接入Redis限流）

### 7.4 数据安全

- **敏感数据**：密码BCrypt加密存储，不可逆
- **SQL注入防护**：JPA参数化查询，避免SQL拼接
- **XSS防护**：前端Vue自动转义

### 7.5 文件安全

- **文件类型校验**：仅允许图片等指定类型
- **文件大小限制**：单文件10MB
- **文件命名**：UUID重命名，防止路径遍历
