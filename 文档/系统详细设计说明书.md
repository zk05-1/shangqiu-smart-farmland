### 2.2 API接口设计

#### 2.2.1 请求封装 request.js

**文件路径**：[utils/request.js](file:///d:/栈可/Documents/商丘智慧农业/zk/框架/client/src/utils/request.js)

**请求拦截器逻辑**：
```
1. 从 localStorage 获取 token
2. 如果 token 存在，添加到请求头 Authorization: Bearer <token>
3. 返回配置
```

**响应拦截器逻辑**：
```
1. 接收响应
2. 取出 data (后端统一响应体 CommonResult)
3. 判断 code:
   - 200：返回 data.data
   - 401：清除token，跳转登录页
   - 其他：弹出错误提示，返回 Promise.reject
4. 网络错误：弹出网络错误提示
```

#### 2.2.2 认证API auth.js

| 方法名 | 参数 | 返回值 | 说明 |

| logout() | 无 | 无 | 退出登录 |
| getUserInfo() | 无 | 用户信息 | 获取当前用户信息 |

## 第3章 后端详细设计

### 3.1 分层设计规范

#### 3.1.1 Controller层

**职责**：
- 接收HTTP请求
- 参数校验
- 调用Service层
- 返回统一响应

**命名规范**：
- 类：`XxxController`
- 方法：`list` / `get` / `add` / `update` / `delete`

**返回值**：统一返回 `CommonResult<T>`

#### 3.1.2 Service层

**职责**：
- 业务逻辑处理
- 事务管理
- 调用Repository层
- 数据转换

**命名规范**：
- 接口：`XxxService`
- 实现类：`XxxServiceImpl`
- 方法：与Controller对应

#### 3.1.3 Repository层

**职责**：
- 数据库CRUD操作
- 自定义查询

**命名规范**：
- 接口：`XxxRepository`
- 继承：`JpaRepository<T, ID>` + `JpaSpecificationExecutor<T>`

#### 3.6.1 JWT工具类 JwtTokenProvider

**核心方法**：

**generateToken(authentication)**
```
输入：认证信息
输出：JWT Token字符串
流程：
1. 从authentication获取用户名
2. 设置claims（用户信息）
3. 设置过期时间

```

**validateToken(token)**
```
输入：Token字符串
输出：boolean
流程：
1. 解析Token
2. 验证签名
3. 检查是否过期

```

**getUsernameFromToken(token)**
```
输入：Token字符串
输出：用户名
流程：
1. 解析Token
2. 从claims中取出subject(用户名)
3. 返回用户名
```

**JWT配置**：
| 配置项 | 值 | 说明 |
|--------|-----|------|
| 密钥 | 配置文件中jwt.secret | 签名密钥 |
| 有效期 | 86400000ms (24小时) | token过期时间 |
| 算法 | HS512 | 签名算法 |
| 前缀 | Bearer | 请求头前缀 |

#### 3.6.2 JWT认证过滤器 JwtAuthenticationFilter

**文件路径**：[security/JwtAuthenticationFilter.java](file:///d:/栈可/Documents/商丘智慧农业/zk/框架/server/src/main/java/com/sqnu/server/security/JwtAuthenticationFilter.java)

**继承**：`OncePerRequestFilter`

**过滤逻辑 doFilterInternal()**：
```
1. 从请求头获取 Authorization
2. 判断是否为 Bearer token
3. 提取token
4. 验证token有效性
5. 有效 → 从token获取用户名
6. 加载用户详情（UserDetailsService）
7. 创建 UsernamePasswordAuthenticationToken
8. 设置到 SecurityContextHolder
9. 继续过滤链
10. 无效或无token → 直接继续过滤链（匿名访问）
```
