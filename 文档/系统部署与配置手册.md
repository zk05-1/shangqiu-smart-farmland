## 第1章 部署概述

### 1.1 系统组成

本系统采用前后端分离架构，由以下部分组成：

| 组件 | 技术栈 | 默认端口 |
|------|--------|----------|
| 前端应用 | Vue 3 + Vite + Element Plus | 5173（开发） / 80（生产） |
| 后端服务 | Spring Boot 3.2.5 + Spring Security + JPA | 8080 |
| 数据库 | MySQL 8.0 | 3306 |

### 1.2 部署模式

- **开发环境**：前后端独立运行，通过Vite代理转发API请求
- **生产环境**：前端构建后部署到Nginx，后端运行Jar包，Nginx反向代理

#### 4.4.3 使用Systemd部署（Linux）

创建服务文件：`/etc/systemd/system/smart-farmland.service`

```ini
[Unit]
Description=Smart Farmland Management System
After=network.target mysql.service

[Service]
Type=simple
User=www
WorkingDirectory=/opt/smart-farmland
ExecStart=/usr/bin/java -Xms512m -Xmx1024m -jar smart-farmland-management-0.0.1-SNAPSHOT.jar
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启动服务：
```bash
systemctl daemon-reload
systemctl start smart-farmland
systemctl enable smart-farmland
systemctl status smart-farmland
```

#### 5.5.1 安装Nginx

**Ubuntu/Debian：**


**CentOS/RHEL：**
```bash

```

**Windows：**

#### 5.5.2 配置Nginx

创建配置文件：`/etc/nginx/conf.d/smart-farmland.conf`

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 替换为你的域名或IP

    # 前端静态资源
    location / {
        root /opt/smart-farmland/dist;
        index index.html;
        try_files $uri $uri/ /index.html;  # Vue Router history模式
    }

    # API反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 上传文件访问
    location /uploads/ {
        proxy_pass http://127.0.0.1:8080/uploads/;
        proxy_set_header Host $host;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

## 第9章 常见问题

### 9.1 后端启动失败

**Q：启动报错"Communications link failure"？**
A：数据库连接失败，请检查：
- MySQL服务是否启动
- 数据库地址、端口是否正确
- 防火墙是否开放3306端口
- 用户名密码是否正确

**Q：启动报错"Table doesn't exist"？**
A：确认 `jpa.hibernate.ddl-auto` 设置为 `update`，首次启动会自动建表。

**Q：启动时报端口被占用？**
A：8080端口被占用，修改 `server.port` 配置或停止占用端口的进程。

```bash
# Windows查看端口占用
netstat -ano | findstr 8080

# Linux查看端口占用
netstat -tlnp | grep 8080
```

### 9.2 前端访问失败

**Q：前端页面空白？**
A：请检查：
- 后端服务是否正常运行
- 接口代理配置是否正确
- 浏览器控制台是否有报错

**Q：接口报403错误？**
A：403表示未授权，需要登录获取token，检查登录状态是否有效。

**Q：地图不显示？**
A：检查高德地图API Key是否正确配置，域名是否在白名单内。

### 9.3 生产环境问题

**Q：Nginx 502 Bad Gateway？**
A：后端服务未启动或地址配置错误，检查后端服务状态和proxy_pass配置。

**Q：刷新页面404？**
A：Vue Router history模式需要Nginx配置 `try_files $uri $uri/ /index.html`

**Q：文件上传失败？**
A：检查：
- 文件上传路径是否存在且有写权限
- 上传文件大小是否超过限制
- Nginx client_max_body_size 配置

## 第10章 安全加固建议

### 10.1 系统安全

- 修改默认管理员密码
- 使用强密码策略
- 定期更新系统和依赖版本
- 配置HTTPS（使用SSL证书）

### 10.2 数据库安全

- 修改默认root密码
- 创建专用数据库用户，最小权限原则
- 禁止远程root登录
- 定期备份数据库

### 10.3 应用安全

- 生产环境关闭SQL日志
- 修改默认JWT密钥
- 配置适当的token有效期
- 限制API请求频率（可选接入Redis限流）

### 10.4 网络安全

- 配置防火墙，只开放必要端口
- 使用VPN或内网访问管理后台
- 配置WAF（Web应用防火墙）
