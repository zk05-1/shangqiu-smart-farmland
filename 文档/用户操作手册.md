## 第1章 系统概述

### 1.1 系统简介

商丘市农业农村局智能农田管理系统是一款面向农业生产管理的综合信息化平台，集成了农田档案管理、作物种植管理、智能灌溉管理、施肥管理、病虫害监测防治、气象数据管理、传感器数据监测、产量预测等核心功能，为农业生产提供全流程数字化管理支持。

### 1.2 系统功能模块

| 模块名称 | 功能说明 |
|----------|----------|
| 数据看板 | 系统核心指标总览，包含统计卡片、数据图表、最新动态 |
| 农田档案 | 农田基础信息管理，支持地图视图展示 |
| 种植管理 | 作物种植全周期记录管理 |
| 灌溉管理 | 智能灌溉记录与管理 |
| 施肥管理 | 施肥记录与精准施肥管理 |
| 病虫害管理 | 病虫害监测与防治记录管理 |
| 气象数据 | 气象数据查询与趋势分析 |
| 传感器数据 | IoT传感器数据实时监测与趋势分析 |
| 产量预测 | AI产量预测模型与结果展示 |
| 系统管理 | 用户、角色、菜单、日志等系统配置 |

### 1.3 运行环境

- **浏览器**：推荐使用 Chrome 90+、Edge 90+、Firefox 88+
- **分辨率**：建议 1920×1080 及以上
- **网络环境**：可访问后端API服务的网络环境

## 第3章 数据看板

### 3.1 功能说明

数据看板是系统的首页，提供系统核心数据的总览展示，帮助用户快速了解农业生产整体情况。

### 3.2 操作说明

#### 3.2.1 统计卡片

页面顶部展示4个核心统计指标：
- **农田总数**：系统中登记的农田总数量
- **种植记录**：当前有效的种植记录数量
- **灌溉记录**：累计灌溉记录数量
- **产量预测**：已生成的产量预测数量

#### 3.2.2 数据图表

- **农田分布饼图**：按使用状态（使用中、休耕、闲置）展示农田数量分布
- **作物种植统计柱状图**：按作物类型统计种植面积
- **气象趋势图**：展示近6个月最高温、最低温、降雨量变化趋势

#### 3.2.3 最新动态

时间线形式展示最近的系统操作记录，点击可查看详情。

### 3.3 注意事项

- 数据看板数据为实时统计，刷新页面后更新
- 点击左侧菜单项可切换到各功能模块

## 第4章 农田档案管理

### 4.1 功能说明

管理全市农田基础信息，支持农田信息的增删改查、地图可视化展示。

### 4.2 操作说明

#### 4.2.1 查询农田

1. 在搜索框输入**关键字**（地块编号/名称/位置）
2. 选择**状态**筛选（使用中/休耕/闲置）
3. 点击"查询"按钮
4. 点击"重置"按钮可清空筛选条件

#### 4.2.2 地图视图

1. 点击"地图视图"按钮
2. 在弹出的地图窗口中查看所有农田位置标记
3. 不同颜色标记代表不同农田状态（绿色-使用中、黄色-休耕、蓝色-闲置）
4. 点击标记点可查看农田详情

#### 4.2.3 新增农田

1. 点击"新增地块"按钮
2. 在弹出的表单中填写农田信息：
   - 地块编号（必填，系统建议格式如SQ-YC-001）
   - 地块名称（必填）
   - 面积（亩，必填）
   - 位置（必填）
   - 经度、纬度（用于地图定位）
   - 土壤类型（壤土/沙土/黏土）
   - 土壤pH值
   - 负责人、联系电话
   - 状态（使用中/休耕/闲置）
3. 点击"确定"保存

#### 4.2.4 编辑农田

1. 在列表中找到目标农田
2. 点击操作列的"编辑"按钮
3. 修改农田信息
4. 点击"确定"保存修改

#### 4.2.5 查看详情

1. 点击操作列的"详情"按钮
2. 查看农田的完整信息

#### 4.2.6 定位农田

1. 点击操作列的"定位"按钮
2. 地图弹窗自动定位到该农田位置
3. 显示农田详细信息

#### 4.2.7 删除农田

1. 点击操作列的"删除"按钮
2. 在确认弹窗中点击"确定"
3. 删除成功后列表自动刷新

#### 4.2.8 批量删除

1. 勾选需要删除的农田（复选框）
2. 点击"批量删除"按钮
3. 确认后批量删除

### 4.3 字段说明

| 字段名称 | 说明 | 必填 |
|----------|------|------|
| 地块编号 | 农田唯一标识，建议按区县编码 | 是 |
| 地块名称 | 农田名称 | 是 |
| 面积 | 农田面积，单位：亩 | 是 |
| 位置 | 农田所在区县乡镇 | 是 |
| 经度 | 地理坐标东经 | 否 |
| 纬度 | 地理坐标北纬 | 否 |
| 土壤类型 | 壤土/沙土/黏土 | 否 |
| 土壤pH值 | 酸碱度，正常范围6.0-8.5 | 否 |
| 负责人 | 农田负责人姓名 | 否 |
| 联系电话 | 负责人电话 | 否 |
| 状态 | 使用中/休耕/闲置 | 是 |

## 第5章 种植管理

### 5.1 功能说明

管理作物种植记录，跟踪作物从播种到收获的全生命周期。

### 5.2 操作说明

#### 5.2.1 查询种植记录

1. 选择**农田**筛选条件
2. 选择**状态**筛选（已播种/生长中/已收获）
3. 点击"查询"按钮

#### 5.2.2 新增种植记录

1. 点击"新增记录"按钮
2. 填写种植信息：
   - 所属农田（必填，下拉选择）
   - 作物类型（必填）
   - 播种日期（必填）
   - 预计收获日期
   - 实际收获日期
   - 种植面积（亩）
   - 播种量（kg）
   - 描述说明
3. 点击"确定"保存

#### 5.2.3 编辑与删除

- 点击"编辑"修改种植记录
- 点击"删除"删除记录

### 5.3 作物类型说明

系统支持多种作物类型：小麦、玉米、棉花、大豆、花生、蔬菜、水果、辣椒、烟叶、西瓜等。

### 5.4 状态流转

```
已播种(PLANTING) → 生长中(GROWING) → 已收获(HARVESTED)
```

## 第6章 灌溉管理

### 6.1 功能说明

记录和管理农田灌溉作业，支持多种灌溉方式。

### 6.2 操作说明

#### 6.2.1 查询灌溉记录

1. 选择**农田**筛选
2. 选择**灌溉方式**筛选（滴灌/喷灌/漫灌）
3. 点击"查询"

#### 6.2.2 新增灌溉记录

1. 点击"新增记录"按钮
2. 填写灌溉信息：
   - 所属农田（必填）
   - 灌溉时间（必填）
   - 用水量（m³，必填）
   - 灌溉方式（滴灌/喷灌/漫灌）
   - 灌溉时长（分钟）
   - 操作人员
   - 描述
3. 点击"确定"保存

### 6.3 灌溉方式说明

| 方式 | 说明 | 特点 |
|------|------|------|
| 滴灌 | 通过滴头缓慢滴水 | 节水效果好，适合经济作物 |
| 喷灌 | 通过喷头喷洒 | 灌溉均匀，适合大田作物 |
| 漫灌 | 传统地面灌溉 | 用水量大，适合水田 |

## 第8章 病虫害管理

### 8.1 功能说明

包含病虫害监测和病虫害防治两个子模块，实现从发现到治理的全流程管理。

### 8.2 病虫害监测

#### 8.2.1 查询监测记录

1. 选择**农田**筛选
2. 选择**类型**筛选（虫害/病害）
3. 选择**严重程度**（轻度/中度/重度）
4. 点击"查询"

#### 8.2.2 新增监测记录

1. 点击"新增监测"按钮
2. 填写监测信息：
   - 所属农田（必填）
   - 病虫害名称（必填）
   - 类型（虫害/病害）
   - 严重程度（轻度/中度/重度）
   - 发现日期
   - 受灾面积（亩）
   - 图片上传
   - 症状描述
3. 点击"确定"保存

### 8.3 病虫害防治

#### 8.3.1 查看防治记录

在监测记录详情中可查看对应的防治记录。

#### 8.3.2 新增防治记录

1. 在监测详情页点击"新增防治"
2. 填写防治信息：
   - 防治方法（化学防治/生物防治/物理防治/农业防治）
   - 农药名称
   - 农药用量
   - 防治时间
   - 防治效果（优秀/良好/一般）
   - 操作人员
   - 防治费用
   - 描述
3. 点击"确定"保存

### 8.4 严重程度说明

| 等级 | 受灾比例 | 处理建议 |
|------|----------|----------|
| 轻度 | 10%以下 | 局部防治，加强监测 |
| 中度 | 10%-30% | 全面防治 |
| 重度 | 30%以上 | 紧急防治，专家会诊 |

## 第9章 气象数据

### 9.1 功能说明

展示商丘市气象数据，支持趋势图表分析，为农业生产提供气象参考。

### 9.2 操作说明

#### 9.2.3 按农田查询

1. 输入**农田ID**
2. 点击"查询"按钮
3. 查看该农田对应区域的气象数据

### 9.3 数据更新说明

- 系统自动同步最新气象数据
- 当天气API不可用时，使用模拟数据保证系统可用性

## 第10章 传感器数据

### 10.1 功能说明

展示IoT传感器实时采集数据，包含土壤、空气、光照、土壤养分等多维度监测指标。

### 10.2 操作说明

#### 10.2.1 查看趋势图表

- **土壤温湿度趋势图**：展示土壤温度和土壤湿度变化曲线
- **空气温湿度趋势图**：展示空气温度和相对湿度变化曲线
- 均为双Y轴设计，温度单位℃，湿度单位%

#### 10.2.2 查看数据列表

展示传感器采集的详细数据：
- 采集时间
- 土壤温度（℃）
- 土壤湿度（%）
- 空气温度（℃）
- 空气湿度（%）
- 光照强度（lux）
- 土壤pH值
- 土壤氮含量（mg/kg）
- 土壤磷含量（mg/kg）
- 土壤钾含量（mg/kg）
- 电导率（mS/m）
- 土壤容重（g/cm³）

#### 10.2.3 按农田查询

1. 输入**农田ID**
2. 点击"查询"按钮
3. 查看该农田的传感器数据

### 10.3 数据采集说明

- 系统每30分钟自动生成一组传感器模拟数据
- 数据基于时间规律和土壤类型特征生成，具有一定真实性
- 实际部署时可接入真实IoT传感器设备

## 第11章 产量预测

### 11.1 功能说明

基于AI模型的产量预测功能，综合气象、土壤、种植等多维度数据进行产量预估。

### 11.2 操作说明

#### 11.2.1 查看预测图表

- **产量预测趋势柱状图**：对比展示各农田预测产量与实际产量
- **预测模型分布饼图**：展示各预测模型的使用分布

#### 11.2.2 查看预测列表

展示预测详情：
- 农田信息（编码、名称）
- 作物类型
- 预测年份
- 预测产量（kg/亩）
- 实际产量（kg/亩）
- 预测模型
- 置信度
- 影响因素

#### 11.2.3 新增预测

1. 点击"新增预测"按钮
2. 填写预测信息：
   - 所属农田（必填）
   - 作物类型
   - 预测年份（必填）
   - 预测产量（kg/亩，必填）
   - 预测模型
   - 置信度（0-1）
   - 影响因素描述
3. 点击"确定"保存

### 11.3 预测模型说明

| 模型名称 | 算法类型 | 特点 |
|----------|----------|------|
| MLP神经网络 | 深度学习 | 拟合能力强，适合复杂非线性关系 |
| 随机森林 | 集成学习 | 抗过拟合，解释性较好 |
| 支持向量机(SVM) | 经典机器学习 | 小样本效果好 |
| 集成学习模型 | 多模型融合 | 综合各模型优势 |
| 回归分析 | 统计方法 | 简单直观，解释性强 |
| 时间序列模型 | 时序分析 | 适合历史产量趋势预测 |

### 11.4 置信度说明

置信度取值范围0-1，数值越高表示预测结果越可靠：
- 0.9以上：高置信度，结果可信度高
- 0.7-0.9：中置信度，结果有参考价值
- 0.7以下：低置信度，结果仅供参考

## 第13章 常见问题

### 13.1 登录相关

**Q：忘记密码怎么办？**
A：请联系系统管理员，由管理员重置密码。

**Q：登录提示"用户名或密码错误"？**
A：请检查用户名和密码是否正确，注意大小写。

**Q：登录后没有权限访问某些菜单？**
A：请联系管理员为您的账号分配相应角色权限。

### 13.2 数据相关

**Q：地图视图不显示地图？**
A：请检查高德地图API Key是否正确配置，网络是否可访问高德地图服务。

**Q：传感器数据一直不更新？**
A：传感器数据每30分钟更新一次，请稍候刷新页面。如长时间不更新，请检查后端定时任务是否正常运行。

**Q：气象数据不准确？**
A：当天气API不可用时系统会使用模拟数据，请配置有效的天气API Key。

### 13.3 操作相关

**Q：删除数据后能恢复吗？**
A：删除操作不可恢复，请谨慎操作。重要数据建议先导出备份。

**Q：新增农田后地图上不显示？**
A：请检查经纬度是否填写正确，确保在合理范围内（商丘市经度约114.5-116.5，纬度约33.5-35.0）。

### 13.4 系统报错

**Q：页面白屏或加载失败？**
A：请按F12打开开发者工具查看控制台错误信息，并联系技术人员处理。

**Q：接口返回403错误？**
A：403表示未授权，请重新登录获取有效token。

**Q：接口返回500错误？**
A：500表示服务器内部错误，请联系技术人员查看后端日志。
