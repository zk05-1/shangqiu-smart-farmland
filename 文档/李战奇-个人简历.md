## 项目经历

### 商丘市农业农村局智能农田管理系统

**项目角色**：全栈开发工程师  
**项目时间**：2026年6月 — 2026年7月  
**项目描述**：为商丘市农业农村局开发的智慧农业管理平台，集农田档案管理、作物种植管理、智能灌溉、精准施肥、病虫害防治、气象监测、IoT 传感器数据采集、AI 产量预测于一体，实现农业生产全流程数字化、智能化管理。

**技术架构**：
- 前后端分离，Vue 3 + Spring Boot 3.2.5
- 分层架构：Controller → Service → Repository 三层结构
- 数据库：MySQL 8.0，17 张数据表，HikariCP 连接池
- 安全体系：JWT 无状态认证 + Spring Security 权限控制 + BCrypt 加密

**核心工作**：

1. **后端架构与接口开发**
   - 基于 Spring Boot 3.2.5 搭建后端服务，设计 17 个 RESTful Controller、18 个 Service、14 个 JPA Repository
   - 实现统一响应封装（CommonResult）、分页结果（PageResult）、全局异常处理（GlobalExceptionHandler）
   - 设计 17 张数据表覆盖农田、种植、灌溉、施肥、病虫害、气象、传感器、产量预测、系统管理等业务域

2. **安全与权限系统**
   - 基于 Spring Security + JWT 实现无状态认证，设计 JwtTokenProvider 与 JwtAuthenticationFilter
   - 实现 RBAC 权限模型：用户-角色-菜单三级权限管理，支持动态菜单加载与接口级权限控制
   - 使用 BCrypt 对用户密码加密存储，保障账户安全

3. **IoT 数据采集与模拟**
   - 开发 SensorDataSimulator 定时任务服务，基于季节气候特征和土壤类型模拟真实 IoT 传感器数据（温度、湿度、土壤墒情等）
   - 实现传感器数据的定时采集、存储与历史趋势查询

4. **气象数据同步服务**
   - 开发 WeatherSyncService，集成第三方气象 API 同步商丘地区实时天气数据
   - 设计降级方案：当第三方 API 不可用时，根据季节特征自动生成模拟气象数据，保证系统高可用

5. **产量预测模块**
   - 设计产量预测数据模型，结合历史种植数据、气象数据、土壤数据进行产量预估
   - 前端使用 ECharts 实现预测趋势柱状图与预测模型分布饼图的可视化展示

6. **地图可视化**
   - 集成高德地图 API，在前端实现农田地理信息的地图标记展示
   - 根据农田状态（使用中/休耕/闲置）使用不同颜色图标标记，超过 10 个标记点时自动启用 MarkerClusterer 聚合

7. **前端页面开发**
   - 开发 10 个功能模块页面：数据看板、农田档案、种植管理、灌溉管理、施肥管理、病虫害管理、气象数据、传感器数据、产量预测、系统管理
   - 使用 Element Plus 构建后台管理界面，ECharts 实现各类数据图表可视化
   - 使用 Pinia 进行全局状态管理，Axios 封装统一请求拦截器处理 Token 与异常

8. **系统管理模块**
   - 实现用户管理、角色管理、菜单管理、操作日志、系统设置五大子模块
   - 支持用户增删改查、角色权限分配、菜单树形结构管理、操作日志审计

**项目成果**：
- 系统涵盖 10 大功能模块、17 张数据表、17 个 API 接口，功能完整可运行
- 完成用户操作手册、系统部署与配置手册、系统架构说明书、系统详细设计说明书四份技术文档
- 系统具备数据模拟降级能力，在第三方服务不可用时仍可正常运行
